### Operator Plan

1.  **Parse Date**: Convert the `DT_STRATA` column from string format (`"M/D/YYYY"`) to a pandas datetime object.
2.  **Format Date**: Convert the parsed datetime into the target string format `"Day DD/MM/YYYY"` (e.g., `"Fri 01/01/2016"`). This new column is named `cst`.
3.  **Rename Hourly Columns**: Map the source columns `PCT_HOURLY_0100` through `PCT_HOURLY_2400` to the target column names `"1:00"` through `"24:00"`. The source column `PCT_HOURLY_2500` is ignored as it does not appear in the target schema.
4.  **Select and Order Columns**: Construct the final DataFrame containing only the `cst` column and the renamed hourly columns in the specified order.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    """
    Transforms the source DataFrame by:
    1. Parsing and formatting the date column DT_STRATA into 'cst'.
    2. Renaming PCT_HOURLY_XXXX columns to H:00 format.
    3. Selecting and ordering the resulting columns.
    """
    # 1. Parse and Format Date
    # Input format: "M/D/YYYY" (e.g., "7/2/2016")
    # Output format: "Day DD/MM/YYYY" (e.g., "Fri 01/01/2016")
    dt_parsed = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    cst_formatted = dt_parsed.dt.strftime('%a %m/%d/%Y')
    
    # 2. Prepare Hourly Columns
    # Source columns are PCT_HOURLY_0100 to PCT_HOURLY_2400
    # Target columns are "1:00" to "24:00"
    
    hourly_cols_source = [f"PCT_HOURLY_{h:04d}" for h in range(1, 25)]
    hourly_cols_target = [f"{h}:00" for h in range(1, 25)]
    
    # Create a mapping dictionary
    col_map = dict(zip(hourly_cols_source, hourly_cols_target))
    
    # Select only the relevant hourly columns and rename them
    # Ensure we only select columns that exist in source to avoid KeyError if schema varies slightly
    existing_hourly_cols = [c for c in hourly_cols_source if c in source.columns]
    df_hourly = source[existing_hourly_cols].rename(columns=col_map)
    
    # 3. Construct Final DataFrame
    # Create a new DataFrame with the formatted date and the renamed hourly data
    result = pd.DataFrame()
    result['cst'] = cst_formatted
    result = pd.concat([result, df_hourly], axis=1)
    
    # Ensure column order matches target specification exactly
    target_cols = ['cst'] + hourly_cols_target
    result = result[target_cols]
    
    return result
```
