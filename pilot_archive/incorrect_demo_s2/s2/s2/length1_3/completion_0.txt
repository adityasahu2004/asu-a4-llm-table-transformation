**Operator Plan:**
1.  **Parse Date**: Convert the `date` column (format `M/D/YYYY`) to a datetime object.
2.  **Format Date**: Create the `cst` column by formatting the parsed datetime as `%a %m/%d/%Y` (e.g., "Wed 01/01/2014").
3.  **Map Hour Columns**: The source has 24 hourly columns with AM/PM labels in a non-chronological order. We need to map these to the target chronological 24-hour format (`1:00` to `24:00`).
    *   `1:00 AM` -> `1:00`
    *   `2:00 AM` -> `2:00`
    *   ...
    *   `11:00 AM` -> `11:00`
    *   `12:00 PM` -> `12:00` (Note: Source has `12:00 AM` and `12:00 PM`. `12:00 PM` is noon, which is hour 12. `12:00 AM` is midnight, which corresponds to hour 24 in this 1-24 schema based on typical load profile conventions where 24:00 is the end of the day/midnight). Let's verify the mapping logic.
        *   Standard 24h clock: 00:00-23:00.
        *   Target labels: 1:00 to 24:00.
        *   Usually, 1:00 AM = 1:00, ..., 11:00 AM = 11:00, 12:00 PM = 12:00, 1:00 PM = 13:00, ..., 11:00 PM = 23:00.
        *   What is 24:00? It typically represents the midnight hour (00:00) or the end of the day. In many energy datasets, 24:00 is the reading for the hour ending at midnight (i.e., 11 PM - 12 AM) or the reading for midnight itself.
        *   Let's look at the source columns: `1:00 AM` ... `11:00 AM`, `12:00 AM`, `1:00 PM` ... `11:00 PM`, `12:00 PM`.
        *   Wait, the source has `12:00 AM` and `12:00 PM`.
        *   Let's check the distinct values or sample data to infer the mapping.
        *   Source: `1:00 AM` ... `11:00 AM` (11 cols), `12:00 AM` (1 col), `1:00 PM` ... `11:00 PM` (11 cols), `12:00 PM` (1 col). Total 24 cols.
        *   Target: `1:00` ... `24:00`.
        *   Mapping hypothesis:
            *   1:00 AM -> 1:00
            *   ...
            *   11:00 AM -> 11:00
            *   12:00 PM -> 12:00
            *   1:00 PM -> 13:00
            *   ...
            *   11:00 PM -> 23:00
            *   12:00 AM -> 24:00
    *   This mapping covers all 24 hours.
4.  **Construct Output**: Create a new DataFrame with `cst` and the 24 renamed hour columns.
5.  **Reset Index**: Ensure the output index is reset.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column
    dt = pd.to_datetime(source['date'], format='%m/%d/%Y')
    
    # Create the cst column with format "DayOfWeek MM/DD/YYYY"
    out = pd.DataFrame()
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Define the mapping from source AM/PM columns to target 24-hour labels
    # Source columns: 1:00 AM ... 11:00 AM, 12:00 AM, 1:00 PM ... 11:00 PM, 12:00 PM
    # Target columns: 1:00 ... 24:00
    
    # Mapping dictionary
    col_map = {}
    
    # 1:00 AM to 11:00 AM -> 1:00 to 11:00
    for h in range(1, 12):
        col_map[f'{h}:00 AM'] = f'{h}:00'
        
    # 12:00 PM -> 12:00
    col_map['12:00 PM'] = '12:00'
    
    # 1:00 PM to 11:00 PM -> 13:00 to 23:00
    for h in range(1, 12):
        col_map[f'{h}:00 PM'] = f'{h+12}:00'
        
    # 12:00 AM -> 24:00
    col_map['12:00 AM'] = '24:00'
    
    # Apply the mapping
    out = out.join(source[list(col_map.keys())].rename(columns=col_map))
    
    # Ensure column order matches target specification (1:00 to 24:00)
    hour_cols = [f'{h}:00' for h in range(1, 25)]
    out = out[['cst'] + hour_cols]
    
    return out.reset_index(drop=True)
```
