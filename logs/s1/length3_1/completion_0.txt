### Operator Plan

1.  **Filter Rows**: The source data contains rows with `DOW` values 'H' (Holiday) and 'D' (Daylight Saving Time adjustment/other). The target data only contains dates corresponding to standard weekdays (1-7). We filter the source DataFrame to keep only rows where `DOW` is in `['1', '2', '3', '4', '5', '6', '7']`.
2.  **Parse and Format Date**:
    *   Parse the `DT_STRATA` column (format `M/D/YYYY`) into a datetime object.
    *   Format this datetime into the target string format `MM/DD/YYYY`.
    *   Assign this new column as `date`.
3.  **Rename Hour Columns**:
    *   The source has columns `PCT_HOURLY_0100` through `PCT_HOURLY_2400`.
    *   The target has columns `Hour 1` through `Hour 24`.
    *   Map `PCT_HOURLY_XXXX` to `Hour N` where `N` is the integer value of `XXXX` divided by 100 (e.g., `0100` -> `1`, `2400` -> `24`).
    *   Note: The source also has `PCT_HOURLY_2500`, which is dropped as it has no corresponding target column.
4.  **Select and Order Columns**:
    *   Select the `date` column and the renamed hour columns.
    *   Ensure the order is `date`, `Hour 1`, ..., `Hour 24`.
5.  **Return Result**: Return the resulting DataFrame.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    """
    Transforms the source DataFrame by filtering for standard weekdays,
    formatting the date, and renaming hourly percentage columns.
    """
    # 1. Filter for standard weekdays (1-7). Exclude 'H' (Holiday) and 'D' (Other/DS).
    valid_dows = ['1', '2', '3', '4', '5', '6', '7']
    df = source[source['DOW'].isin(valid_dows)].copy()
    
    # 2. Parse and format the date
    # Source format is M/D/YYYY (e.g., "7/2/2016")
    # Target format is MM/DD/YYYY (e.g., "07/02/2016")
    df['date'] = pd.to_datetime(df['DT_STRATA'], format='%m/%d/%Y').dt.strftime('%m/%d/%Y')
    
    # 3. Rename hourly columns
    # Source: PCT_HOURLY_0100 ... PCT_HOURLY_2400
    # Target: Hour 1 ... Hour 24
    
    rename_map = {}
    for i in range(1, 25):
        src_col = f"PCT_HOURLY_{i:04d}"
        tgt_col = f"Hour {i}"
        if src_col in df.columns:
            rename_map[src_col] = tgt_col
            
    df.rename(columns=rename_map, inplace=True)
    
    # 4. Select and order columns
    # Target columns: date, Hour 1, ..., Hour 24
    target_cols = ['date'] + [f"Hour {i}" for i in range(1, 25)]
    
    # Ensure we only select columns that exist (though logic above guarantees it for 1-24)
    final_cols = [col for col in target_cols if col in df.columns]
    
    result = df[final_cols]
    
    return result
```
