### Operator Plan

1.  **Parse Timestamp**: Convert the `timestamp` column from string to datetime objects to extract temporal features.
2.  **Extract Time Features**: Create `month` (1-12) and `hour` (0-23) columns from the parsed timestamp.
3.  **Map Source Columns to Target Columns**: Identify the source columns corresponding to the target energy categories based on naming conventions:
    *   `hvac`: Sum of `AC COMPRESSOR WHS [emon ch3,4]`, `AIR HANDLER WHS [emon ch5,6]`, `Minisplit WHS (2-CTs) [xpod chA-7,8]`.
    *   `water_heating`: `WATER HEATER WHS [emon ch7,8]`.
    *   `refrigerator`: Sum of `Primary Fridge WHS [emon ch12]` and `2nd Fridge WHS [emon ch13]`.
    *   `clothes_washer`: Constant 0 (no direct source column, target shows all 0s).
    *   `clothes_dryer`: Sum of `DRYER WHS (1-CT) [emon ch9]` and `Dryer WHS (2-CTs) [xpod chA-9,10]`.
    *   `dishwasher`: `DISH WASHER WHS [emon ch11]`.
    *   `cooking_range`: `RANGE WHS (1-CT) [emon ch10]`.
    *   `pool_spa_pumps`: `POOL PUMP WHS (2-CTs) [xpod chA-3,4]`.
    *   `interior_lighting`: Constant 0.
    *   `exterior_lighting`: Constant 0.
    *   `lighting`: Constant 0.
    *   `plug`: Constant 0.
    *   `pool_spa_heater`: Constant 0.
4.  **Handle Missing/Invalid Data**: The source data uses `32767.0` as a sentinel value for missing/invalid data. The target data preserves these values in the mapped columns (e.g., `hvac` has values like `98301.0` which is `32767 * 3`, and `32767.0` in single-source columns). Therefore, we perform arithmetic operations directly on the source values without replacing `32767.0` with NaN, as the target expects the arithmetic result of the sentinels.
5.  **Construct Result**: Assemble the new DataFrame with the specified column order and dtypes. Ensure integer columns (`month`, `hour`, `clothes_washer`, etc.) are cast to `int64`.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # 1. Parse timestamp
    source = source.copy()
    source['timestamp_dt'] = pd.to_datetime(source['timestamp'])
    
    # 2. Extract month and hour
    month = source['timestamp_dt'].dt.month.astype('int64')
    hour = source['timestamp_dt'].dt.hour.astype('int64')
    
    # 3. Map and compute target columns
    # Note: Source uses 32767.0 as a sentinel. Target preserves arithmetic results of these sentinels.
    
    # HVAC: AC Compressor + Air Handler + Minisplit
    hvac = (
        source['AC COMPRESSOR WHS [emon ch3,4]'] +
        source['AIR HANDLER WHS [emon ch5,6]'] +
        source['Minisplit WHS (2-CTs) [xpod chA-7,8]']
    )
    
    # Water Heating
    water_heating = source['WATER HEATER WHS [emon ch7,8]']
    
    # Refrigerator: Primary + 2nd
    refrigerator = (
        source['Primary Fridge WHS [emon ch12]'] +
        source['2nd Fridge WHS [emon ch13]']
    )
    
    # Clothes Washer: Constant 0
    clothes_washer = pd.Series(0, index=source.index, dtype='int64')
    
    # Clothes Dryer: Dryer (1-CT) + Dryer (2-CTs)
    clothes_dryer = (
        source['DRYER WHS (1-CT) [emon ch9]'] +
        source['Dryer WHS (2-CTs) [xpod chA-9,10]']
    )
    
    # Dishwasher
    dishwasher = source['DISH WASHER WHS [emon ch11]']
    
    # Cooking Range
    cooking_range = source['RANGE WHS (1-CT) [emon ch10]']
    
    # Pool/Spa Pumps
    pool_spa_pumps = source['POOL PUMP WHS (2-CTs) [xpod chA-3,4]']
    
    # Lighting and Plug categories are constant 0 in target
    interior_lighting = pd.Series(0, index=source.index, dtype='int64')
    exterior_lighting = pd.Series(0, index=source.index, dtype='int64')
    lighting = pd.Series(0, index=source.index, dtype='int64')
    plug = pd.Series(0, index=source.index, dtype='int64')
    pool_spa_heater = pd.Series(0, index=source.index, dtype='int64')
    
    # 4. Construct final DataFrame
    result = pd.DataFrame({
        'month': month,
        'hour': hour,
        'hvac': hvac,
        'water_heating': water_heating,
        'refrigerator': refrigerator,
        'clothes_washer': clothes_washer,
        'clothes_dryer': clothes_dryer,
        'dishwasher': dishwasher,
        'cooking_range': cooking_range,
        'pool_spa_pumps': pool_spa_pumps,
        'interior_lighting': interior_lighting,
        'exterior_lighting': exterior_lighting,
        'lighting': lighting,
        'plug': plug,
        'pool_spa_heater': pool_spa_heater
    })
    
    return result
```
