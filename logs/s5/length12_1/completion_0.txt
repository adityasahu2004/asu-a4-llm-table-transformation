Operator plan:
1. Parse the `time` column into a datetime object.
2. Derive `season` based on the month:
   - Winter: Dec, Jan, Feb
   - Spring: Mar, Apr, May
   - Summer: Jun, Jul, Aug
   - (Fall/Sep-Oct is not in target distinct values, but standard logic applies if present; target only shows Summer/Winter/Spring).
3. Derive `hour` from the hour component of the timestamp (0-23).
4. Select and rename specific source columns to target names, aggregating where necessary:
   - `hvac`: Sum of heating and cooling related electricity columns. Specifically: `electricity_heating_kwh`, `electricity_central_system_heating_kwh`, `electricity_cooling_kwh`, `electricity_central_system_cooling_kwh`, `electricity_fans_heating_kwh`, `electricity_fans_cooling_kwh`, `electricity_pumps_heating_kwh`, `electricity_central_system_pumps_heating_kwh`, `electricity_pumps_cooling_kwh`, `electricity_central_system_pumps_cooling_kwh`.
   - `water_heating`: `electricity_water_systems_kwh`
   - `refrigerator`: `electricity_refrigerator_kwh`
   - `clothes_washer`: `electricity_clothes_washer_kwh`
   - `clothes_dryer`: `electricity_clothes_dryer_kwh`
   - `dishwasher`: `electricity_dishwasher_kwh`
   - `cooking_range`: `electricity_cooking_range_kwh`
   - `pool_spa_pumps`: Sum of `electricity_pool_pump_kwh` and `electricity_hot_tub_pump_kwh`
   - `interior_lighting`: `electricity_interior_lighting_kwh`
   - `exterior_lighting`: `electricity_exterior_lighting_kwh`
   - `lighting`: Sum of `interior_lighting` and `exterior_lighting`
   - `plug`: `electricity_plug_loads_kwh`
   - `pool_spa_heaters`: Sum of `electricity_pool_heater_kwh` and `electricity_hot_tub_heater_kwh`
5. Group by `season` and `hour` and sum the values.
6. Sort and reset index.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse time
    df = source.copy()
    df['time_dt'] = pd.to_datetime(df['time'])
    
    # Derive Season
    month = df['time_dt'].dt.month
    def get_season(m):
        if m in [12, 1, 2]:
            return 'Winter'
        elif m in [3, 4, 5]:
            return 'Spring'
        elif m in [6, 7, 8]:
            return 'Summer'
        elif m in [9, 10, 11]:
            return 'Fall' # Not in target sample but good to handle
        return 'Unknown'
    
    df['season'] = month.apply(get_season)
    
    # Derive Hour
    df['hour'] = df['time_dt'].dt.hour
    
    # Define HVAC components
    hvac_cols = [
        'electricity_heating_kwh',
        'electricity_central_system_heating_kwh',
        'electricity_cooling_kwh',
        'electricity_central_system_cooling_kwh',
        'electricity_fans_heating_kwh',
        'electricity_fans_cooling_kwh',
        'electricity_pumps_heating_kwh',
        'electricity_central_system_pumps_heating_kwh',
        'electricity_pumps_cooling_kwh',
        'electricity_central_system_pumps_cooling_kwh'
    ]
    
    # Create intermediate columns for aggregation
    df['hvac'] = df[hvac_cols].sum(axis=1)
    df['water_heating'] = df['electricity_water_systems_kwh']
    df['refrigerator'] = df['electricity_refrigerator_kwh']
    df['clothes_washer'] = df['electricity_clothes_washer_kwh']
    df['clothes_dryer'] = df['electricity_clothes_dryer_kwh']
    df['dishwasher'] = df['electricity_dishwasher_kwh']
    df['cooking_range'] = df['electricity_cooking_range_kwh']
    df['pool_spa_pumps'] = df['electricity_pool_pump_kwh'] + df['electricity_hot_tub_pump_kwh']
    df['interior_lighting'] = df['electricity_interior_lighting_kwh']
    df['exterior_lighting'] = df['electricity_exterior_lighting_kwh']
    df['lighting'] = df['interior_lighting'] + df['exterior_lighting']
    df['plug'] = df['electricity_plug_loads_kwh']
    df['pool_spa_heaters'] = df['electricity_pool_heater_kwh'] + df['electricity_hot_tub_heater_kwh']
    
    # Aggregate
    agg_cols = [
        'hvac', 'water_heating', 'refrigerator', 'clothes_washer', 
        'clothes_dryer', 'dishwasher', 'cooking_range', 'pool_spa_pumps',
        'interior_lighting', 'exterior_lighting', 'lighting', 'plug', 'pool_spa_heaters'
    ]
    
    result = df.groupby(['season', 'hour'])[agg_cols].sum().reset_index()
    
    # Ensure correct order of columns
    target_cols = [
        'season', 'hour', 'hvac', 'water_heating', 'refrigerator', 
        'clothes_washer', 'clothes_dryer', 'dishwasher', 'cooking_range', 
        'pool_spa_pumps', 'interior_lighting', 'exterior_lighting', 
        'lighting', 'plug', 'pool_spa_heaters'
    ]
    
    return result[target_cols]
```
