Operator plan: Parse the source `date` column; format it as ISO datetime string for the target `date` column. Rename `value1`...`value24` to `Hour 1`...`Hour 24`. Drop all other columns.

```python
import pandas as pd
def transform(source: pd.DataFrame) -> pd.DataFrame:
    out = pd.DataFrame(index=source.index)
    out['date'] = pd.to_datetime(source['date']).dt.strftime('%Y-%m-%d %H:%M:%S')
    for h in range(1, 25):
        out[f'Hour {h}'] = source[f'value{h}']
    return out.reset_index(drop=True)
```
