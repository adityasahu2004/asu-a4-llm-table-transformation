Operator plan:
1. Parse the `date` column into datetime objects to compute the day of the week.
2. Format the date as `M/D/YYYY` for the `dt_strata` column.
3. Compute `dow` as the day of the week where Monday=0, ..., Sunday=6 (standard Python/pandas `dayofweek`).
4. Rename the `Hour 1` through `Hour 24` columns to `pct_hourly_0100` through `pct_hourly_2400`.
5. Add a new column `pct_hourly_2500` filled with NaN.
6. Return the resulting DataFrame.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse dates
    dates = pd.to_datetime(source['date'])
    
    # Create output dataframe
    out = pd.DataFrame(index=source.index)
    
    # Format dt_strata as M/D/YYYY
    out['dt_strata'] = dates.dt.strftime('%-m/%-d/%Y')
    
    # Compute dow (Monday=0, Sunday=6)
    out['dow'] = dates.dt.dayofweek
    
    # Rename hourly columns
    for h in range(1, 25):
        out[f'pct_hourly_{h:02d}00'] = source[f'Hour {h}']
        
    # Add pct_hourly_2500 as NaN
    out['pct_hourly_2500'] = np.nan
    
    return out.reset_index(drop=True)
```
