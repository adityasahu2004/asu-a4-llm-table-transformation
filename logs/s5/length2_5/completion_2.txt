Operator plan:
1. Parse the `date` column into datetime objects.
2. Create `dt_strata` by formatting the parsed dates as `M/D/YYYY` (using `%m/%d/%Y` which drops leading zeros for single-digit months/days, matching the target sample `1/1/2015`).
3. Create `dow` by extracting the day of the week (0=Monday, 6=Sunday) from the parsed dates.
4. Rename the 24 hourly columns from `Hour N` to `pct_hourly_NN00`.
5. Add a new column `pct_hourly_2500` filled with `NaN`.
6. Return the resulting DataFrame.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse dates
    dates = pd.to_datetime(source['date'], format='%m/%d/%Y')
    
    # Create output dataframe
    out = pd.DataFrame(index=source.index)
    
    # Format dt_strata as M/D/YYYY
    out['dt_strata'] = dates.dt.strftime('%m/%d/%Y')
    
    # Calculate dow (0=Monday, ..., 6=Sunday)
    out['dow'] = dates.dt.dayofweek
    
    # Map Hour 1..24 to pct_hourly_0100..pct_hourly_2400
    for h in range(1, 25):
        src_col = f'Hour {h}'
        tgt_col = f'pct_hourly_{h:02d}00'
        out[tgt_col] = source[src_col]
        
    # Add pct_hourly_2500 with NaNs
    out['pct_hourly_2500'] = np.nan
    
    return out.reset_index(drop=True)
```
