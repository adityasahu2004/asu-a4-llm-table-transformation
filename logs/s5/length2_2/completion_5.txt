Operator plan: Parse the `date` column; format it as `MM/DD/YYYY` for `dt_strata`; compute ISO day-of-week (Monday=1...Sunday=7) for `dow`; rename `value1`..`value24` to `pct_hourly_0100`..`pct_hourly_2400`; append a constant zero column `pct_hourly_2500`.

```python
import pandas as pd
def transform(source: pd.DataFrame) -> pd.DataFrame:
    dates = pd.to_datetime(source['date'], format='%m/%d/%Y')
    out = pd.DataFrame(index=source.index)
    out['dt_strata'] = dates.dt.strftime('%m/%d/%Y')
    out['dow'] = dates.dt.dayofweek + 1
    for h in range(1, 25):
        out[f'pct_hourly_{h:02d}00'] = source[f'value{h}']
    out['pct_hourly_2500'] = 0
    return out.reset_index(drop=True)
```
