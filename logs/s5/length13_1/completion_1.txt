**Operator Plan:**
1.  **Parse Datetime**: Convert the `time` column to a datetime object and format it as `YYYY-MM-DD HH:MM:SS` for the `datetime` column.
2.  **Aggregate HVAC**: Sum `electricity_heating_kwh`, `electricity_cooling_kwh`, `electricity_fans_heating_kwh`, `electricity_fans_cooling_kwh`, `electricity_pumps_heating_kwh`, `electricity_pumps_cooling_kwh`, `electricity_central_system_heating_kwh`, `electricity_central_system_cooling_kwh`, `electricity_central_system_pumps_heating_kwh`, and `electricity_central_system_pumps_cooling_kwh` to create `hvac`.
3.  **Aggregate Domestic Water Heating**: Use `electricity_water_systems_kwh` for `domestic_water_heating`.
4.  **Aggregate Major Appliances**: Sum `electricity_refrigerator_kwh`, `electricity_clothes_washer_kwh`, `electricity_clothes_dryer_kwh`, `electricity_cooking_range_kwh`, and `electricity_dishwasher_kwh` to create `major_appliances`.
5.  **Aggregate Lighting**: Sum `electricity_interior_lighting_kwh` and `electricity_exterior_lighting_kwh` to create `lighting`.
6.  **Aggregate Miscellaneous Plug Loads**: Sum `electricity_plug_loads_kwh`, `electricity_house_fan_kwh`, `electricity_range_fan_kwh`, `electricity_bath_fan_kwh`, `electricity_ceiling_fan_kwh`, `electricity_pool_heater_kwh`, `electricity_pool_pump_kwh`, `electricity_hot_tub_heater_kwh`, and `electricity_hot_tub_pump_kwh` to create `miscellaneous_plug_loads`.
7.  **Total**: Use `net_site_electricity_kwh` for `total`.
8.  **Construct Result**: Create a new DataFrame with the calculated columns and reset the index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse time and format
    dt = pd.to_datetime(source['time'], format='%Y-%m-%d %H:%M:%S.%f')
    out = pd.DataFrame()
    out['datetime'] = dt.dt.strftime('%Y-%m-%d %H:%M:%S')
    
    # HVAC Components
    hvac_cols = [
        'electricity_heating_kwh',
        'electricity_cooling_kwh',
        'electricity_fans_heating_kwh',
        'electricity_fans_cooling_kwh',
        'electricity_pumps_heating_kwh',
        'electricity_pumps_cooling_kwh',
        'electricity_central_system_heating_kwh',
        'electricity_central_system_cooling_kwh',
        'electricity_central_system_pumps_heating_kwh',
        'electricity_central_system_pumps_cooling_kwh'
    ]
    out['hvac'] = source[hvac_cols].sum(axis=1)
    
    # Domestic Water Heating
    out['domestic_water_heating'] = source['electricity_water_systems_kwh']
    
    # Major Appliances
    major_appl_cols = [
        'electricity_refrigerator_kwh',
        'electricity_clothes_washer_kwh',
        'electricity_clothes_dryer_kwh',
        'electricity_cooking_range_kwh',
        'electricity_dishwasher_kwh'
    ]
    out['major_appliances'] = source[major_appl_cols].sum(axis=1)
    
    # Lighting
    lighting_cols = [
        'electricity_interior_lighting_kwh',
        'electricity_exterior_lighting_kwh'
    ]
    out['lighting'] = source[lighting_cols].sum(axis=1)
    
    # Miscellaneous Plug Loads
    misc_cols = [
        'electricity_plug_loads_kwh',
        'electricity_house_fan_kwh',
        'electricity_range_fan_kwh',
        'electricity_bath_fan_kwh',
        'electricity_ceiling_fan_kwh',
        'electricity_pool_heater_kwh',
        'electricity_pool_pump_kwh',
        'electricity_hot_tub_heater_kwh',
        'electricity_hot_tub_pump_kwh'
    ]
    out['miscellaneous_plug_loads'] = source[misc_cols].sum(axis=1)
    
    # Total
    out['total'] = source['net_site_electricity_kwh']
    
    return out.reset_index(drop=True)
```
