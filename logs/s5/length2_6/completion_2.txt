**Operator Plan:**
1.  **Parse Date**: Convert the `Date` column from string format (`%m/%d/%Y`) to datetime objects to extract the day of the week.
2.  **Derive Day of Week (DOW)**: Calculate the day of the week as an integer (0=Monday, ..., 6=Sunday) using `dt.weekday`.
3.  **Format Date String**: Format the parsed date back to a string in `MM/DD/YYYY` format for the `dt_strata` column.
4.  **Rename Hour Columns**: Map the source columns `Hr 1` through `Hr 24` to the target schema names `pct_hourly_0100` through `pct_hourly_2400`.
5.  **Add Constant Column**: Create a new column `pct_hourly_2500` filled with zeros (integer type).
6.  **Construct Output**: Assemble the new DataFrame with the calculated columns and reset the index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date to extract DOW and format string
    dt_series = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    
    # Create output dataframe
    out = pd.DataFrame()
    
    # 1. dt_strata: formatted date string MM/DD/YYYY
    out['dt_strata'] = dt_series.dt.strftime('%m/%d/%Y')
    
    # 2. dow: integer day of week (0=Monday, 6=Sunday)
    out['dow'] = dt_series.dt.weekday
    
    # 3. Hourly columns: Rename Hr 1..24 to pct_hourly_0100..2400
    for h in range(1, 25):
        source_col = f'Hr {h}'
        target_col = f'pct_hourly_{h:02d}00'
        out[target_col] = source[source_col]
        
    # 4. pct_hourly_2500: Constant 0
    out['pct_hourly_2500'] = 0
    
    return out.reset_index(drop=True)
```
