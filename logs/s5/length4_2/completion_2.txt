**Operator Plan:**

1.  **Date Parsing & Formatting**: Parse the `date` column from the source (format `%m/%d/%Y`) into a datetime object. Format it to the target string format `YYYY-MM-DD 00:00:00`.
2.  **Column Selection & Renaming**: Select the 24 value columns (`value1` through `value24`). Rename them according to the specific target schema which uses a non-standard 12-hour clock ordering:
    *   Hours 1-11 (Source `value1`-`value11`) map to `1:00 AM` - `11:00 AM`.
    *   Hour 12 (Source `value12`) maps to `12:00 AM` (Midnight).
    *   Hours 13-23 (Source `value13`-`value23`) map to `1:00 PM` - `11:00 PM`.
    *   Hour 24 (Source `value24`) maps to `12:00 PM` (Noon).
3.  **Construct Result**: Create a new DataFrame with the formatted date column and the renamed value columns. Reset index.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse dates and format to target string pattern
    dt_series = pd.to_datetime(source['date'], format='%m/%d/%Y')
    formatted_dates = dt_series.dt.strftime('%Y-%m-%d 00:00:00')
    
    # Define the mapping from source value columns to target hour labels
    # Target order: 1-11 AM, 12 AM, 1-11 PM, 12 PM
    # Source order: value1 (1 AM) ... value11 (11 AM), value12 (12 AM), 
    #               value13 (1 PM) ... value23 (11 PM), value24 (12 PM)
    
    target_columns = [
        '1:00 AM', '2:00 AM', '3:00 AM', '4:00 AM', '5:00 AM', '6:00 AM', 
        '7:00 AM', '8:00 AM', '9:00 AM', '10:00 AM', '11:00 AM', 
        '12:00 AM',
        '1:00 PM', '2:00 PM', '3:00 PM', '4:00 PM', '5:00 PM', '6:00 PM', 
        '7:00 PM', '8:00 PM', '9:00 PM', '10:00 PM', '11:00 PM', 
        '12:00 PM'
    ]
    
    source_value_cols = [f'value{i}' for i in range(1, 25)]
    
    # Create the result dataframe
    out = pd.DataFrame(index=source.index)
    out['date'] = formatted_dates
    
    # Map values
    for target_col, source_col in zip(target_columns, source_value_cols):
        out[target_col] = source[source_col]
        
    return out.reset_index(drop=True)
```
