**Operator Plan:**

1.  **Parse Date**: Convert the `CST` column (format `%a %m/%d/%Y`) to a pandas datetime object.
2.  **Format Date**: Create the `date` column by formatting the parsed datetime as `%m/%d/%Y`.
3.  **Map Hours**: The source has columns `1:00` through `24:00:00`. The target requires a specific 12-hour clock format with AM/PM indicators.
    *   Hours 1-11 map to `1:00 AM` - `11:00 AM`.
    *   Hour 12 maps to `12:00 AM` (Midnight).
    *   Hour 13 maps to `1:00 PM`.
    *   Hours 14-23 map to `2:00 PM` - `11:00 PM`.
    *   Hour 24 maps to `12:00 PM` (Noon).
    *   Note: The target column order is specific: 1AM..11AM, 12AM, 1PM..11PM, 12PM. We must construct the DataFrame with this exact column order.
4.  **Construct DataFrame**: Select and rename the relevant columns from the source, preserving the float values.
5.  **Return**: Reset index and return the new DataFrame.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date from CST column
    # Format: "Sat 12/01/2012" -> %a %m/%d/%Y
    dt = pd.to_datetime(source['CST'], format='%a %m/%d/%Y')
    
    # Create date column in MM/DD/YYYY format
    out = pd.DataFrame()
    out['date'] = dt.dt.strftime('%m/%d/%Y')
    
    # Define the mapping from source hour columns to target hour columns
    # Source: 1:00 to 24:00:00
    # Target: 1:00 AM ... 11:00 AM, 12:00 AM, 1:00 PM ... 11:00 PM, 12:00 PM
    
    # Helper to get source column name
    def get_src_col(h):
        if h == 24:
            return '24:00:00'
        return f'{h}:00'
        
    # Helper to get target column name
    def get_tgt_col(h):
        if h == 12:
            return '12:00 AM'
        if h == 24:
            return '12:00 PM'
        
        h_12 = h % 12
        if h_12 == 0:
            h_12 = 12
            
        if h < 12:
            return f'{h_12}:00 AM'
        else:
            return f'{h_12}:00 PM'

    # The target order is specific:
    # 1AM, 2AM, ..., 11AM, 12AM, 1PM, ..., 11PM, 12PM
    # This corresponds to source hours:
    # 1, 2, ..., 11, 12, 13, ..., 23, 24
    
    target_order_hours = list(range(1, 12)) + [12] + list(range(13, 24)) + [24]
    
    for h in target_order_hours:
        src_col = get_src_col(h)
        tgt_col = get_tgt_col(h)
        out[tgt_col] = source[src_col].values
        
    return out.reset_index(drop=True)
```
