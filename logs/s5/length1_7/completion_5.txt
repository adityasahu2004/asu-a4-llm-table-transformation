**Operator Plan:**
1.  **Parse Date**: Convert the `Date` column (format `%a %m/%d/%Y`) to a datetime object.
2.  **Format Date**: Create the `cst` column by formatting the parsed datetime as `%a %m/%d/%Y`.
3.  **Rename Columns**: Map the source hourly columns (`1:00` through `23:00` and `24:00:00`) to the target hourly columns (`1:00` through `24:00`). Note that the source column `24:00:00` becomes `24:00`.
4.  **Select and Order**: Select the `cst` column followed by the 24 hourly columns in order.
5.  **Reset Index**: Return the resulting DataFrame with a default integer index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date string to datetime
    dt = pd.to_datetime(source['Date'], format='%a %m/%d/%Y')
    
    # Create the target 'cst' column with the same format
    out = pd.DataFrame()
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Map source hourly columns to target hourly columns
    # Source has '1:00'...'23:00' and '24:00:00'
    # Target has '1:00'...'24:00'
    
    for h in range(1, 24):
        out[f'{h}:00'] = source[f'{h}:00']
        
    # Handle the 24th hour specifically due to name difference
    out['24:00'] = source['24:00:00']
    
    # Ensure column order matches target specification
    cols = ['cst'] + [f'{h}:00' for h in range(1, 25)]
    out = out[cols]
    
    return out.reset_index(drop=True)
```
