Operator plan: Parse CST to extract date and day-of-week; format date as MM/DD/YYYY; compute ISO day-of-week (Monday=1...Sunday=7); rename the 24 hourly columns to pct_hourly_0100 through pct_hourly_2400; append a constant 0 column for pct_hourly_2500.

```python
import pandas as pd
def transform(source: pd.DataFrame) -> pd.DataFrame:
    dates = pd.to_datetime(source['CST'], format='%a %m/%d/%Y')
    out = pd.DataFrame(index=source.index)
    out['dt_strata'] = dates.dt.strftime('%m/%d/%Y')
    out['dow'] = dates.dt.dayofweek + 1
    for h in range(1, 25):
        src_col = f'{h}:00' if h < 24 else '24:00:00'
        out[f'pct_hourly_{h:02d}00'] = pd.to_numeric(source[src_col], errors='coerce')
    out['pct_hourly_2500'] = 0
    return out.reset_index(drop=True)
```
