**Operator Plan:**
1.  **Parse Date**: Convert the `Date` column from string (`%m/%d/%Y`) to datetime objects.
2.  **Format Date**: Create the `cst` column by formatting the parsed datetime as `%a %m/%d/%Y` (e.g., "Tue 01/01/2013").
3.  **Rename Columns**: Map the integer hour columns (`1` through `24`) to the target format (`1:00` through `24:00`).
4.  **Select and Order**: Construct the final DataFrame with `cst` followed by the renamed hourly columns, preserving the original row order.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column
    dt = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    
    # Create the target 'cst' column
    out = pd.DataFrame()
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Map integer hour columns to 'H:00' format
    for h in range(1, 25):
        out[f'{h}:00'] = source[str(h)]
        
    return out
```
