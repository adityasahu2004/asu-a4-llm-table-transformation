**Operator Plan:**

1.  **Parse Date**: Convert the `Date` column (format `%m/%d/%Y`) into a pandas datetime object.
2.  **Format Date**: Format the parsed datetime into the target `cst` column format (`%a %m/%d/%Y`, e.g., "Tue 01/01/2013").
3.  **Rename Columns**: Map the source numeric hour columns (`1` through `24`) to the target hour columns (`1:00` through `24:00`).
4.  **Select and Construct**: Construct the final DataFrame with the formatted `cst` column and the renamed hourly columns.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column
    dates = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    
    # Create the output dataframe
    out = pd.DataFrame()
    
    # Format the date for the 'cst' column
    out['cst'] = dates.dt.strftime('%a %m/%d/%Y')
    
    # Rename the hourly columns from 1..24 to 1:00..24:00
    for h in range(1, 25):
        out[f'{h}:00'] = source[h]
        
    return out
```
