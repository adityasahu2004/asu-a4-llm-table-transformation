Operator plan: Parse the source `Date` column into datetime objects. Format this datetime into the target `cst` string format (`%a %m/%d/%Y`). Rename the numeric hour columns (1-24) to the target format (`1:00` through `24:00`). Drop the `Class` column as it is not in the target. Return the new DataFrame with the specified columns.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date
    dt = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    
    # Create output dataframe
    out = pd.DataFrame()
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Rename hour columns
    for h in range(1, 25):
        out[f'{h}:00'] = source[h]
        
    return out
```
