**Operator Plan:**
1.  **Parse Date:** Convert the `Date` column from `MM/DD/YYYY` format to a pandas datetime object.
2.  **Format Date:** Format the parsed datetime into `YYYY-MM-DD 00:00:00` string format for the target `date` column.
3.  **Rename Columns:** Rename the integer hour columns (`1` through `24`) to `value1` through `value24`.
4.  **Select and Order:** Select the new `date` column and the renamed value columns in the correct order.
5.  **Reset Index:** Return the resulting DataFrame with a clean integer index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column
    dates = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    
    # Create the output dataframe
    out = pd.DataFrame()
    
    # Format date as required: YYYY-MM-DD 00:00:00
    out['date'] = dates.dt.strftime('%Y-%m-%d %H:%M:%S')
    
    # Rename hourly columns from "1"..."24" to "value1"..."value24"
    for h in range(1, 25):
        out[f'value{h}'] = source[str(h)]
        
    # Reset index to ensure clean output
    return out.reset_index(drop=True)
```
