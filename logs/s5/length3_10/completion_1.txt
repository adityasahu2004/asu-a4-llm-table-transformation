Operator plan:
1. Parse the `Date` column (format `%a %m/%d/%Y`) into datetime objects.
2. Create a new `date` column formatted as `MM/DD/YYYY`.
3. Select the 24 hourly columns from the source. Note that the 24th hour column is named `24:00:00` in the source, while others are `H:00`.
4. Rename these columns to `Hour 1` through `Hour 24`.
5. Return the DataFrame with the new schema.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date
    dates = pd.to_datetime(source['Date'], format='%a %m/%d/%Y')
    
    # Create output dataframe
    out = pd.DataFrame()
    out['date'] = dates.dt.strftime('%m/%d/%Y')
    
    # Map source hourly columns to target hourly columns
    # Source columns: "1:00" ... "23:00", "24:00:00"
    # Target columns: "Hour 1" ... "Hour 24"
    
    for h in range(1, 25):
        if h == 24:
            src_col = '24:00:00'
        else:
            src_col = f'{h}:00'
        
        out[f'Hour {h}'] = source[src_col]
        
    return out
```
