Operator plan: Parse the `date` column into datetime objects. Format the date as "Weekday MM/DD/YYYY" for the `cst` column. Rename `value1` through `value24` to `1:00` through `24:00`. Drop other columns. Reset index.

```python
import pandas as pd
def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse dates
    dt = pd.to_datetime(source['date'], format='%m/%d/%Y')
    
    # Create output dataframe
    out = pd.DataFrame(index=source.index)
    
    # Format cst column
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Rename value columns to hour labels
    for h in range(1, 25):
        out[f'{h}:00'] = source[f'value{h}']
        
    return out.reset_index(drop=True)
```
