Operator plan:
1. Parse the `DT_STRATA` column into datetime objects.
2. Format the datetime as `MM/DD/YYYY` for the `date` column.
3. Select the 24 hourly columns (`PCT_HOURLY_0100` through `PCT_HOURLY_2400`).
4. Rename these columns to `Hour 1` through `Hour 24`.
5. Return the resulting DataFrame with the new column order.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format
    dt = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    out = pd.DataFrame()
    out['date'] = dt.dt.strftime('%m/%d/%Y')
    
    # Map hourly columns
    for h in range(1, 25):
        src_col = f'PCT_HOURLY_{h:02d}00'
        tgt_col = f'Hour {h}'
        out[tgt_col] = source[src_col]
        
    return out
```
