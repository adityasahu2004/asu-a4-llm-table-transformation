Operator plan:
1. Parse `DT_STRATA` to datetime and format as `MM/DD/YYYY` for the `Date` column.
2. Select the 24 hourly columns (`PCT_HOURLY_0100` through `PCT_HOURLY_2400`).
3. Rename these columns to `Hr 1` through `Hr 24`.
4. Return the resulting DataFrame with `Date` followed by the hourly columns.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format as MM/DD/YYYY
    dates = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    date_strs = dates.dt.strftime('%m/%d/%Y')
    
    # Build the output DataFrame
    out = pd.DataFrame()
    out['Date'] = date_strs
    
    # Map hourly columns 0100-2400 to Hr 1-Hr 24
    for h in range(1, 25):
        src_col = f'PCT_HOURLY_{h:02d}00'
        tgt_col = f'Hr {h}'
        out[tgt_col] = source[src_col]
        
    return out
```
