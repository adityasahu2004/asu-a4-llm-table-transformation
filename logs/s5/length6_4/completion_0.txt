Operator plan:
1. Parse the `date` column from `m/d/Y` format to datetime.
2. Format the parsed datetime into `YYYY-MM-DD 00:00:00` string for the target `Date` column.
3. Map the source hourly columns (which use 12-hour AM/PM notation) to the target 24-hour indices (1-24).
   - "1:00 AM" -> Hr 1, ..., "11:00 AM" -> Hr 11
   - "12:00 PM" -> Hr 12 (Noon)
   - "1:00 PM" -> Hr 13, ..., "11:00 PM" -> Hr 23
   - "12:00 AM" -> Hr 24 (Midnight end of day)
4. Construct the output DataFrame with columns `Date` and `Hr 1` through `Hr 24`.
5. Reset index.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date
    dates = pd.to_datetime(source['date'], format='%m/%d/%Y')
    
    # Format date to target string format
    out = pd.DataFrame(index=source.index)
    out['Date'] = dates.dt.strftime('%Y-%m-%d 00:00:00')
    
    # Define mapping from source column names to target hour indices
    # Source columns are like "1:00 AM", "12:00 PM", etc.
    # Target columns are "Hr 1" to "Hr 24"
    
    # 1 AM -> 1, 2 AM -> 2, ..., 11 AM -> 11
    # 12 PM -> 12
    # 1 PM -> 13, 2 PM -> 14, ..., 11 PM -> 23
    # 12 AM -> 24
    
    col_mapping = {
        '1:00 AM': 1,
        '2:00 AM': 2,
        '3:00 AM': 3,
        '4:00 AM': 4,
        '5:00 AM': 5,
        '6:00 AM': 6,
        '7:00 AM': 7,
        '8:00 AM': 8,
        '9:00 AM': 9,
        '10:00 AM': 10,
        '11:00 AM': 11,
        '12:00 PM': 12,
        '1:00 PM': 13,
        '2:00 PM': 14,
        '3:00 PM': 15,
        '4:00 PM': 16,
        '5:00 PM': 17,
        '6:00 PM': 18,
        '7:00 PM': 19,
        '8:00 PM': 20,
        '9:00 PM': 21,
        '10:00 PM': 22,
        '11:00 PM': 23,
        '12:00 AM': 24
    }
    
    for src_col, hr_idx in col_mapping.items():
        out[f'Hr {hr_idx}'] = source[src_col]
        
    return out.reset_index(drop=True)
```
