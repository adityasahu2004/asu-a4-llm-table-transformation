**Operator Plan:**
1.  **Parse Date**: Convert the `date` column from string format (`%m/%d/%Y`) to datetime objects.
2.  **Format Date**: Convert the parsed datetime to the target string format (`YYYY-MM-DD 00:00:00`).
3.  **Rename Columns**: Map the source columns `value1` through `value24` to `Hr 1` through `Hr 24`.
4.  **Select Columns**: Construct the final DataFrame containing only the new `Date` column and the renamed hourly columns.
5.  **Reset Index**: Ensure the output has a clean integer index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column
    dt = pd.to_datetime(source['date'], format='%m/%d/%Y')
    
    # Create the output dataframe
    out = pd.DataFrame()
    
    # Format the date as requested: YYYY-MM-DD 00:00:00
    out['Date'] = dt.dt.strftime('%Y-%m-%d 00:00:00')
    
    # Rename and select the hourly value columns
    for i in range(1, 25):
        out[f'Hr {i}'] = source[f'value{i}']
        
    # Reset index to ensure clean integer index
    return out.reset_index(drop=True)
```
