**Operator Plan:**
1.  **Date Parsing & Formatting**: Parse the `date` column (format `%m/%d/%Y`) into datetime objects. Format these as ISO 8601 strings (`YYYY-MM-DD 00:00:00`) for the target column `Date`.
2.  **Column Renaming**: Rename the 24 hourly value columns (`value1` through `value24`) to `Hr 1` through `Hr 24`.
3.  **Projection**: Select only the new `Date` column and the renamed hourly columns. Drop all other columns (`class`, `Description`, `analysis`, `uom`).
4.  **Index Reset**: Reset the index to ensure a clean 0-based integer index in the output.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format to ISO string with time component
    dt_series = pd.to_datetime(source['date'], format='%m/%d/%Y')
    
    # Create the output dataframe
    out = pd.DataFrame(index=source.index)
    out['Date'] = dt_series.dt.strftime('%Y-%m-%d %H:%M:%S')
    
    # Rename value1..value24 to Hr 1..Hr 24
    for i in range(1, 25):
        out[f'Hr {i}'] = source[f'value{i}']
        
    return out.reset_index(drop=True)
```
