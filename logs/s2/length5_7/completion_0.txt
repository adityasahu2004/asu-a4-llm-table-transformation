**Operator Plan:**
1.  **Parse Date**: Convert the `Date` column from string format (e.g., "7/3/2013") to a pandas datetime object.
2.  **Format Date**: Convert the parsed datetime to the target string format `YYYY-MM-DD 00:00:00` and assign to the new column `date`.
3.  **Rename Columns**: Map the source numeric columns (`1` through `24`) to the target column names (`value1` through `value24`).
4.  **Select Columns**: Construct the final DataFrame containing only the `date` column and the renamed value columns, discarding `Class` and other unused columns.
5.  **Reset Index**: Ensure the resulting DataFrame has a clean integer index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column
    dt = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    
    # Format the date to the target string format
    out = pd.DataFrame()
    out['date'] = dt.dt.strftime('%Y-%m-%d 00:00:00')
    
    # Rename and select the hourly value columns
    for h in range(1, 25):
        out[f'value{h}'] = source[str(h)]
        
    return out.reset_index(drop=True)
```
