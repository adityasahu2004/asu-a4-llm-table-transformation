Operator plan: Parse DT_STRATA into a datetime object and format it as MM/DD/YYYY for the `date` column. Select the 24 hourly percentage columns (`PCT_HOURLY_0100` through `PCT_HOURLY_2400`) and rename them to `value1` through `value24`. Discard all other columns.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format
    dt = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    out = pd.DataFrame()
    out['date'] = dt.dt.strftime('%m/%d/%Y')
    
    # Map hourly columns to value1...value24
    for i in range(1, 25):
        src_col = f'PCT_HOURLY_{i:02d}00'
        tgt_col = f'value{i}'
        out[tgt_col] = source[src_col]
        
    return out.reset_index(drop=True)
```
