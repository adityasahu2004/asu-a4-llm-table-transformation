**Operator Plan:**
1.  **Parse Date**: Convert the `Date` column from string format (`%m/%d/%Y`) to a datetime object.
2.  **Format Date**: Convert the parsed datetime to the target string format (`YYYY-MM-DD 00:00:00`) and assign to the new column `date`.
3.  **Rename Columns**: Map the source hourly columns (`Hr 1` through `Hr 24`) to the target column names (`value1` through `value24`).
4.  **Select Columns**: Construct the final DataFrame containing only the `date` column and the renamed hourly value columns, preserving the original row order.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column
    dt = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    
    # Format the date as required by the target schema
    out = pd.DataFrame()
    out['date'] = dt.dt.strftime('%Y-%m-%d 00:00:00')
    
    # Map source hourly columns to target value columns
    for i in range(1, 25):
        out[f'value{i}'] = source[f'Hr {i}']
        
    return out
```
