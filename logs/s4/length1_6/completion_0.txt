**Operator Plan:**
1.  **Date Parsing and Formatting**: Parse the `Date` column (format `%m/%d/%Y`) into datetime objects. Format this datetime into the target `cst` column format `%a %m/%d/%Y` (e.g., "Wed 01/01/2014").
2.  **Column Renaming**: Map the source hourly columns (`Hr 1` through `Hr 24`) to the target hourly columns (`1:00` through `24:00`). The mapping is `f"Hr {h}"` -> `f"{h}:00"` for `h` in 1..24.
3.  **Selection**: Select only the newly created `cst` column and the renamed hourly columns, discarding `Company`, `Rate`, and `Rate Code`.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format to 'Day MM/DD/YYYY'
    dt = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    out = pd.DataFrame()
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Rename hourly columns from 'Hr X' to 'X:00'
    for h in range(1, 25):
        out[f'{h}:00'] = source[f'Hr {h}']
        
    return out
```
