**Operator Plan:**
1.  **Date Parsing & Formatting**: Parse the `Date` column (format `m/d/Y`) into datetime objects. Format this datetime into the target `cst` string format (`%a %m/%d/%Y`, e.g., "Wed 01/01/2014").
2.  **Column Renaming**: Rename the hourly columns from `Hr 1` through `Hr 24` to `1:00` through `24:00`.
3.  **Selection**: Select only the new `cst` column and the renamed hourly columns, discarding `Company`, `Rate`, and `Rate Code`.
4.  **Reset Index**: Ensure the resulting DataFrame has a clean integer index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format to 'cst'
    dt = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    out = pd.DataFrame()
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Map Hr 1..24 to 1:00..24:00
    for h in range(1, 25):
        out[f'{h}:00'] = source[f'Hr {h}']
        
    return out.reset_index(drop=True)
```
