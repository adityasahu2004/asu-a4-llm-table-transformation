**Operator Plan:**
1.  **Date Parsing & Formatting**: Parse the `Date` column (format `M/D/YYYY`) into datetime objects. Format this into the target `cst` column using the pattern `%a %m/%d/%Y` (e.g., "Wed 01/01/2014").
2.  **Column Renaming**: Rename the hourly columns from `Hr 1` through `Hr 24` to `1:00` through `24:00`.
3.  **Projection**: Select only the `cst` column and the 24 renamed hourly columns, discarding `Company`, `Rate`, and `Rate Code`.
4.  **Reset Index**: Ensure the output DataFrame has a clean integer index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format to 'cst'
    dates = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    out = pd.DataFrame(index=source.index)
    out['cst'] = dates.dt.strftime('%a %m/%d/%Y')
    
    # Rename hourly columns
    for h in range(1, 25):
        out[f'{h}:00'] = source[f'Hr {h}']
        
    return out.reset_index(drop=True)
```
