Operator plan: Parse CST; extract month name padded to 10 chars; derive daytype (weekend/weekday); rename the 24 hour columns to hr1–hr24.

```python
import pandas as pd
def transform(source: pd.DataFrame) -> pd.DataFrame:
    dates = pd.to_datetime(source['CST'], format='%a %m/%d/%Y')
    out = pd.DataFrame(index=source.index)
    out['month'] = dates.dt.strftime('%B').str.ljust(10)
    dow = dates.dt.dayofweek
    out['daytype'] = dow.apply(lambda x: 'weekend' if x >= 5 else 'weekday')
    for h in range(1,25):
        src_col = f'{h}:00' if h < 24 else '24:00:00'
        out[f'hr{h}'] = pd.to_numeric(source[src_col], errors='coerce')
    return out.reset_index(drop=True)
```
