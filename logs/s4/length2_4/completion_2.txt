**Operator Plan:**
1.  **Parse Date**: Convert the `Date` column from string format (`%m/%d/%Y`) to a pandas datetime object.
2.  **Format Date**: Convert the parsed datetime to a string in the format `%m/%d/%Y` for the `dt_strata` column.
3.  **Derive Day of Week**: Calculate the ISO day of the week (Monday=0, ..., Sunday=6) from the parsed datetime and assign it to the `dow` column.
4.  **Rename Hour Columns**: Iterate through hours 1 to 24. Map the source column names (strings `"1"` through `"24"`) to the target column names (`"pct_hourly_0100"` through `"pct_hourly_2400"`).
5.  **Add Null Column**: Create the `pct_hourly_2500` column filled with `NaN` values.
6.  **Construct Result**: Assemble the new DataFrame with the specified column order and return it.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the source date
    dates = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    
    # Construct the output DataFrame
    out = pd.DataFrame(index=source.index)
    
    # Format dt_strata as MM/DD/YYYY
    out['dt_strata'] = dates.dt.strftime('%m/%d/%Y')
    
    # Calculate dow: Monday=0, ..., Sunday=6
    out['dow'] = dates.dt.dayofweek.astype('int64')
    
    # Map hours 1-24
    for h in range(1, 25):
        src_col = str(h)
        tgt_col = f'pct_hourly_{h:02d}00'
        out[tgt_col] = source[src_col]
        
    # Add the 25th hour column as null
    out['pct_hourly_2500'] = np.nan
    
    # Reset index to match target schema expectations (default integer index)
    return out.reset_index(drop=True)
```
