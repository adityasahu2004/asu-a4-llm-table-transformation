Operator plan:
1. Parse `DT_STRATA` into a datetime object and format it as `MM/DD/YYYY` for the `Date` column.
2. Select the 24 hourly columns (`PCT_HOURLY_0100` through `PCT_HOURLY_2400`).
3. Rename these columns to `Hr 1` through `Hr 24`.
4. Return the resulting DataFrame with the `Date` column first, followed by the renamed hourly columns.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format as MM/DD/YYYY
    dates = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    df_out = pd.DataFrame()
    df_out['Date'] = dates.dt.strftime('%m/%d/%Y')
    
    # Map hourly columns to new names
    for h in range(1, 25):
        src_col = f'PCT_HOURLY_{h:02d}00'
        tgt_col = f'Hr {h}'
        df_out[tgt_col] = source[src_col]
        
    return df_out.reset_index(drop=True)
```
