**Operator Plan:**
1.  **Filter**: Retain only rows where `Rate` is "R4". This isolates the specific rate class required for the aggregation, as other rates (S1, S2, etc.) have different structures or values not present in the target sample.
2.  **Parse Date**: Convert the `Date` column to datetime to extract the month.
3.  **Melt/Unpivot**: Transform the wide hourly columns (`Hr 1` to `Hr 24`) into a long format with columns `hour` and `value`.
4.  **Aggregate**: Group by `hour` and `month` (1-12). Sum the `value` for each group. The target data shows sums (e.g., ~700-900 for Jan hour 1, which corresponds to summing ~31 days of values around 2.0-3.0).
5.  **Pivot/Reshape**: Pivot the aggregated data so that `hour` becomes the index, months become columns (named `january`, `february`, etc.), and the values are the sums.
6.  **Format**: Reset index, rename columns to match target schema, and ensure `hour` is integer type. Sort by `hour`.

import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # 1. Filter for Rate 'R4'
    df = source[source['Rate'] == 'R4'].copy()
    
    # 2. Parse Date to extract Month
    df['dt'] = pd.to_datetime(df['Date'], format='%m/%d/%Y')
    df['month'] = df['dt'].dt.month
    
    # 3. Melt hourly columns
    # Identify hourly columns
    hour_cols = [f'Hr {i}' for i in range(1, 25)]
    
    df_melted = df.melt(
        id_vars=['month'], 
        value_vars=hour_cols, 
        var_name='hour_label', 
        value_name='value'
    )
    
    # Extract hour number from label 'Hr 1' -> 1

    # 4. Aggregate: Sum values for each hour and month

    # being a subset or having different scaling than the "evaluation source" mentioned in the note.
