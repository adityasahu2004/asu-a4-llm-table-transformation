**Operator Plan:**

1.  **Parse Date:** Convert the `date` column (format `M/D/YYYY`) to a pandas datetime object.
2.  **Format Date:** Create the `cst` column by formatting the parsed datetime as `%a %m/%d/%Y` (e.g., "Sat 01/01/2011").
3.  **Map Values:** Iterate through hours 1 to 24. For each hour `h`, map the source column `value{h}` to the target column `{h}:00`.
4.  **Construct Output:** Build a new DataFrame with the `cst` column and the 24 hourly columns, preserving the row order. Reset the index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date string
    dt = pd.to_datetime(source['date'], format='%m/%d/%Y')
    
    # Format the date for the 'cst' column
    out = pd.DataFrame()
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Map value1..value24 to 1:00..24:00
    for h in range(1, 25):
        out[f'{h}:00'] = source[f'value{h}']
        
    return out.reset_index(drop=True)
```
