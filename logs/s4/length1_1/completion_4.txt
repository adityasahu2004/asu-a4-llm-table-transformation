Operator plan: Parse DT_STRATA into datetime objects to derive the weekday abbreviation and format the date as "DDD MM/DD/YYYY" for the `cst` column. Select the 24 hourly columns (`PCT_HOURLY_0100` through `PCT_HOURLY_2400`), rename them to "1:00" through "24:00", and construct the resulting DataFrame. Drop identifiers and the 25th hour column.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse dates
    dt = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    
    # Create the 'cst' column: "Fri 01/01/2016"
    # %a gives abbreviated weekday name (e.g., Fri)
    out = pd.DataFrame(index=source.index)
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Map the 24 hourly columns to "1:00" ... "24:00"
    for h in range(1, 25):
        src_col = f'PCT_HOURLY_{h:02d}00'
        tgt_col = f'{h}:00'
        out[tgt_col] = source[src_col]
        
    return out.reset_index(drop=True)
```
