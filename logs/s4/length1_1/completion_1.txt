Operator plan: Parse `DT_STRATA` to datetime, format as `%a %m/%d/%Y` for `cst`. Select and rename the 24 hourly columns (`PCT_HOURLY_0100` to `PCT_HOURLY_2400`) to `1:00` through `24:00`. Drop other columns.

```python
import pandas as pd
def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format cst
    dt = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    out = pd.DataFrame()
    out['cst'] = dt.dt.strftime('%a %m/%d/%Y')
    
    # Rename and select hourly columns
    for h in range(1, 25):
        src_col = f'PCT_HOURLY_{h:02d}00'
        tgt_col = f'{h}:00'
        out[tgt_col] = source[src_col]
        
    return out.reset_index(drop=True)
```
