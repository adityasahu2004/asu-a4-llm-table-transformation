**Operator Plan:**
1.  **Parse Date**: Convert the `date` column (format `%m/%d/%Y`) to datetime.
2.  **Format Date**: Create the `Date` column by formatting the datetime as `YYYY-MM-DD 00:00:00`.
3.  **Rename Columns**: Map the source columns `value1` through `value24` to the target columns `Hr 1` through `Hr 24`.
4.  **Select and Reorder**: Construct the final DataFrame with the new `Date` column followed by the 24 renamed hourly columns.
5.  **Reset Index**: Ensure the output has a clean integer index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column
    dt = pd.to_datetime(source['date'], format='%m/%d/%Y')
    
    # Create the target DataFrame
    out = pd.DataFrame()
    out['Date'] = dt.dt.strftime('%Y-%m-%d %H:%M:%S')
    
    # Map value1...value24 to Hr 1...Hr 24
    for i in range(1, 25):
        out[f'Hr {i}'] = source[f'value{i}']
        
    return out.reset_index(drop=True)
```
