**Operator Plan:**
1.  **Parse Date**: Convert the `DT_STRATA` column (format `M/D/YYYY`) into a datetime object.
2.  **Format Date**: Convert the parsed datetime into the target string format `MM/DD/YYYY` for the `date` column.
3.  **Select and Rename Columns**: Select the 24 hourly percentage columns (`PCT_HOURLY_0100` through `PCT_HOURLY_2400`). Rename them to `Hour 1` through `Hour 24` respectively.
4.  **Construct Result**: Combine the formatted `date` column and the renamed hourly columns into the final DataFrame. Drop any other columns not required by the target schema.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date column from source format 'M/D/YYYY'
    dates = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    
    # Format to target string 'MM/DD/YYYY'
    date_str = dates.dt.strftime('%m/%d/%Y')
    
    # Map source hourly columns to target hourly columns
    hourly_cols = [f'PCT_HOURLY_{h:02d}00' for h in range(1, 25)]
    target_hourly_cols = [f'Hour {h}' for h in range(1, 25)]
    
    # Create the result dataframe
    result = pd.DataFrame()
    result['date'] = date_str
    
    for src_col, tgt_col in zip(hourly_cols, target_hourly_cols):
        result[tgt_col] = source[src_col]
        
    return result
```
