Operator plan:
1. Parse the `time` column to extract `month` (1-12) and `hour` (0-23).
2. Construct the `hvac` column by summing all electricity consumption columns related to heating, cooling, fans, and pumps (central and non-central).
3. Construct the `water_heating` column from `electricity_water_systems_kwh`.
4. Map specific appliance columns to new names: `refrigerator`, `clothes_washer`, `clothes_dryer`, `dishwasher`, `cooking_range`, `interior_lighting`, `exterior_lighting`, `plug` (from `electricity_plug_loads_kwh`), `pool_spa_pumps` (sum of pool pump and hot tub pump), and `pool_spa_heater` (sum of pool heater and hot tub heater).
5. Construct `lighting` as the sum of `interior_lighting` and `exterior_lighting`.
6. Return the DataFrame with the specified columns.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse time
    dt = pd.to_datetime(source['time'], format='%Y-%m-%d %H:%M:%S.%f')
    
    out = pd.DataFrame(index=source.index)
    out['month'] = dt.dt.month
    out['hour'] = dt.dt.hour
    
    # HVAC components: heating, cooling, fans, pumps (central and otherwise)
    hvac_cols = [
        'electricity_heating_kwh',
        'electricity_central_system_heating_kwh',
        'electricity_cooling_kwh',
        'electricity_central_system_cooling_kwh',
        'electricity_fans_heating_kwh',
        'electricity_fans_cooling_kwh',
        'electricity_pumps_heating_kwh',
        'electricity_central_system_pumps_heating_kwh',
        'electricity_pumps_cooling_kwh',
        'electricity_central_system_pumps_cooling_kwh'
    ]
    hvac_sum = sum(source[col] for col in hvac_cols)
    out['hvac'] = hvac_sum
    
    # Water heating
    out['water_heating'] = source['electricity_water_systems_kwh']
    
    # Appliances
    out['refrigerator'] = source['electricity_refrigerator_kwh']
    out['clothes_washer'] = source['electricity_clothes_washer_kwh']
    out['clothes_dryer'] = source['electricity_clothes_dryer_kwh']
    out['dishwasher'] = source['electricity_dishwasher_kwh']
    out['cooking_range'] = source['electricity_cooking_range_kwh']
    
    # Lighting
    out['interior_lighting'] = source['electricity_interior_lighting_kwh']
    out['exterior_lighting'] = source['electricity_exterior_lighting_kwh']
    out['lighting'] = out['interior_lighting'] + out['exterior_lighting']
    
    # Plug loads
    out['plug'] = source['electricity_plug_loads_kwh']
    
    # Pool/Spa Pumps
    out['pool_spa_pumps'] = source['electricity_pool_pump_kwh'] + source['electricity_hot_tub_pump_kwh']
    
    # Pool/Spa Heaters
    out['pool_spa_heater'] = source['electricity_pool_heater_kwh'] + source['electricity_hot_tub_heater_kwh']
    
    # Ensure column order matches target
    cols = [
        'month', 'hour', 'hvac', 'water_heating', 'refrigerator', 
        'clothes_washer', 'clothes_dryer', 'dishwasher', 'cooking_range', 
        'pool_spa_pumps', 'interior_lighting', 'exterior_lighting', 
        'lighting', 'plug', 'pool_spa_heater'
    ]
    
    return out[cols].reset_index(drop=True)
```
