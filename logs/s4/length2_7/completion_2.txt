**Operator plan:**
1.  **Parse Date:** Parse the `Date` column from the format `"%a %m/%d/%Y"` into a datetime object.
2.  **Format Date:** Create the `dt_strata` column by formatting the parsed datetime as `"%m/%d/%y"` (2-digit year, as observed in target sample "01/01/03").
3.  **Extract Day of Week:** Create the `dow` column using the ISO weekday (Monday=1, Sunday=7) derived from the parsed datetime.
4.  **Map Hourly Columns:** Rename and map the 24 hourly columns (`1:00` through `24:00:00`) to the target schema (`pct_hourly_0100` through `pct_hourly_2400`).
    *   Columns `1:00` to `23:00` map directly to `pct_hourly_0100` to `pct_hourly_2300`.
    *   Column `24:00:00` maps to `pct_hourly_2400`.
5.  **Add Null Column:** Add the `pct_hourly_2500` column filled with `NaN` (as observed in the target schema where distinct is 0 and nulls match row count).
6.  **Construct Output:** Return the DataFrame with the specified columns in order, resetting the index.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the date
    dt = pd.to_datetime(source['Date'], format='%a %m/%d/%Y')
    
    # Create output dataframe
    out = pd.DataFrame(index=source.index)
    
    # Format date as MM/DD/YY
    out['dt_strata'] = dt.dt.strftime('%m/%d/%y')
    
    # Extract ISO day of week (1=Mon, 7=Sun)
    out['dow'] = dt.dt.dayofweek + 1
    
    # Map hourly columns
    for h in range(1, 24):
        src_col = f"{h}:00"
        tgt_col = f"pct_hourly_{h:02d}00"
        out[tgt_col] = source[src_col]
        
    # Handle the 24th hour specifically due to source column name '24:00:00'
    out['pct_hourly_2400'] = source['24:00:00']
    
    # Add the 25th hour as null
    out['pct_hourly_2500'] = np.nan
    
    # Define target column order
    cols = ['dt_strata', 'dow'] + [f'pct_hourly_{h:02d}00' for h in range(1, 26)]
    
    return out[cols].reset_index(drop=True)
```
