**Operator Plan:**
1.  **Date Parsing & Formatting**: Parse the `Date` column from the source (format `%m/%d/%Y`) into datetime objects. Format these dates into the target string format `%m/%d/%Y` and assign to the new `Date` column.
2.  **Column Renaming**: Select the 24 hourly numeric columns from the source (named `1` through `24`). Rename them to `Hr 1` through `Hr 24` to match the target schema.
3.  **Projection**: Construct the final DataFrame containing only the formatted `Date` and the renamed hourly columns. Reset the index to ensure a clean 0-based integer index.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse dates and format to MM/DD/YYYY
    dates = pd.to_datetime(source['Date'], format='%m/%d/%Y')
    formatted_dates = dates.dt.strftime('%m/%d/%Y')
    
    # Create output dataframe
    out = pd.DataFrame()
    out['Date'] = formatted_dates
    
    # Rename hourly columns 1-24 to Hr 1 - Hr 24
    for h in range(1, 25):
        out[f'Hr {h}'] = source[str(h)]
        
    return out.reset_index(drop=True)
```
