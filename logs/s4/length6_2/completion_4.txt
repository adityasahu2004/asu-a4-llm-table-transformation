**Operator Plan:**
1.  Parse the `CST` column (format `%a %m/%d/%Y`) into a datetime object.
2.  Create a new column `Date` by formatting the parsed datetime as `%m/%d/%Y`.
3.  Select the 24 hourly columns from the source. Note that the 24th hour column in the source is named `24:00:00`, while hours 1-23 are named `1:00` through `23:00`.
4.  Rename these columns to `Hr 1` through `Hr 24`.
5.  Return the resulting DataFrame with `Date` followed by the hourly columns.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse the CST column to datetime
    dt = pd.to_datetime(source['CST'], format='%a %m/%d/%Y')
    
    # Create the Date column in MM/DD/YYYY format
    out = pd.DataFrame()
    out['Date'] = dt.strftime('%m/%d/%Y')
    
    # Map source hour columns to target hour columns
    # Source: '1:00'...'23:00', '24:00:00'
    # Target: 'Hr 1'...'Hr 24'
    
    for h in range(1, 24):
        out[f'Hr {h}'] = source[f'{h}:00']
    
    # Handle the 24th hour specifically as its source name is '24:00:00'
    out['Hr 24'] = source['24:00:00']
    
    return out
```
