Operator plan: Parse DT_STRATA into datetime and format as MM/DD/YYYY for the `date` column. Rename the 24 hourly percentage columns (`PCT_HOURLY_0100` through `PCT_HOURLY_2400`) to `value1` through `value24`. Drop other columns.

```python
import pandas as pd

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # Parse date and format
    dt = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    
    out = pd.DataFrame()
    out['date'] = dt.dt.strftime('%m/%d/%Y')
    
    # Rename hourly columns
    for i in range(1, 25):
        src_col = f'PCT_HOURLY_{i:02d}00'
        tgt_col = f'value{i}'
        out[tgt_col] = source[src_col]
        
    return out
```
