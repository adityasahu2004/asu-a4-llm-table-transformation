Operator plan: Parse CST into datetime; format date as MM/DD/YYYY; rename the 24 hour columns (handling '24:00:00' for the last one) to 'Hour 1'...'Hour 24'.

```python
import pandas as pd
def transform(source: pd.DataFrame) -> pd.DataFrame:
    out = pd.DataFrame(index=source.index)
    out['date'] = pd.to_datetime(source['CST'], format='%a %m/%d/%Y').dt.strftime('%m/%d/%Y')
    for h in range(1, 25):
        src_name = f'{h}:00' if h < 24 else '24:00:00'
        out[f'Hour {h}'] = pd.to_numeric(source[src_name], errors='coerce')
    return out.reset_index(drop=True)
```
