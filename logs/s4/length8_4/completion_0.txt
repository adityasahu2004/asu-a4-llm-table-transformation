**Operator Plan:**
1.  **Parse Dates**: Convert `DT_STRATA` to datetime objects to extract the month and day-of-week (or just month for grouping).
2.  **Select Columns**: Identify the 24 hourly columns (`PCT_HOURLY_0100` to `PCT_HOURLY_2400`).
3.  **Group and Aggregate**: Group the source data by the hour (derived from column names) and the month (derived from `DT_STRATA`). Calculate the mean of the hourly values for each group.
    *   *Assumption*: The target values appear to be averages (means) of the hourly percentages for each specific hour across all dates within that month. The distinct counts in the target (e.g., 22 for January) suggest aggregation over the dates in that month.
4.  **Reshape**: Pivot or reshape the aggregated data so that rows represent the hours (1-24) and columns represent the months (January-December).
5.  **Format Output**:
    *   Create an `hour` column with integer values 1-24.
    *   Create month columns named `january` through `december`.
    *   Ensure the order of rows is by `hour` ascending.

```python
import pandas as pd
import numpy as np

def transform(source: pd.DataFrame) -> pd.DataFrame:
    # 1. Parse DT_STRATA to get month information
    source = source.copy()
    source['DT_STRATA'] = pd.to_datetime(source['DT_STRATA'], format='%m/%d/%Y')
    source['month'] = source['DT_STRATA'].dt.month
    
    # 2. Identify hourly columns
    hour_cols = [c for c in source.columns if c.startswith('PCT_HOURLY_') and c != 'PCT_HOURLY_2500']
    # Sort them to ensure correct order if needed, though groupby handles names
    hour_cols.sort()
    
    # 3. Melt the dataframe to long format for aggregation
    # We only need the month and the hourly values
    long_df = source[['month'] + hour_cols].melt(
        id_vars=['month'], 
        value_vars=hour_cols, 
        var_name='hour_col', 
        value_name='value'
    )
    
    # 4. Extract hour number from column name (e.g., 'PCT_HOURLY_0100' -> 1)
    long_df['hour'] = long_df['hour_col'].apply(lambda x: int(x.split('_')[1][:2]))
    
    # 5. Aggregate: Mean of values for each hour and month
    agg_df = long_df.groupby(['hour', 'month'])['value'].mean().reset_index()
    
    # 6. Pivot to wide format: rows=hour, cols=month
    pivot_df = agg_df.pivot(index='hour', columns='month', values='value')
    
    # 7. Rename columns to month names
    month_names = {
        1: 'january', 2: 'february', 3: 'march', 4: 'april', 5: 'may', 6: 'june',
        7: 'july', 8: 'august', 9: 'september', 10: 'october', 11: 'november', 12: 'december'
    }
    pivot_df.rename(columns=month_names, inplace=True)
    
    # 8. Reset index to make 'hour' a column and ensure it's integer
    pivot_df.reset_index(inplace=True)
    pivot_df['hour'] = pivot_df['hour'].astype(int)
    
    # 9. Ensure column order matches target specification
    target_cols = ['hour'] + [month_names[i] for i in range(1, 13)]
    
    # Fill NaNs if any month is missing for an hour (though unlikely in this dense dataset)
    pivot_df = pivot_df.fillna(0.0)
    
    # Select and order columns
    result = pivot_df[target_cols]
    
    # Sort by hour just in case
    result = result.sort_values('hour').reset_index(drop=True)
    
    return result
```
